📖 JSON 工具使用指南

1. 快速美化：粘贴杂乱无章的单行或混淆 JSON 字符串后，点击“格式化”即可自动按层级缩进排版。
2. 错误捕获：若 JSON 语法有误（如多余的逗号、缺少双引号），工具会自动提示具体错误原因。

💡 JSON 数据格式与规范科普

1. 什么是 JSON？ JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。它基于 JavaScript 语法子集，完全独立于语言，是现代 Web 开发与 API 接口传输的核心标准。
2. 常见语法陷阱 标准的 JSON 要求所有键名（Key）必须使用双引号包裹，且末尾元素不能有多余的逗号（Trailing Comma），否则将导致解析失败。
